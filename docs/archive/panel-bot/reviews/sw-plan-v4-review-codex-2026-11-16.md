# SW-PLAN-v4.0 독립 구현 착수 검토 — Codex

## 결론

검토일은 2026-11-16이며 대상은 `docs/plan/SW-PLAN-v4.0.md` 1–435행이다. 검토한 원본 SHA-256은 `8e075ce913440ce3c160c266b23b439d8283775261ca89b3ac019d51dabee68c`이다. 공식 소스·문서 확인 시각은 **2026-11-16 05:39–05:43 UTC**이며, 공개 브랜치와 로봇 설치 버전의 일치는 확인하지 않았다. 다른 검토자 파일을 읽지 않고 계획서, 본인의 이전 판단, 공식 소스를 대조했다.

**v4.0은 v3.0보다 구현 범위가 명확하며 코어·도구 개발의 출발점으로 사용할 수 있지만, 현재 규칙 그대로 안전 게이트와 주행을 구현해서는 안 된다.** 특히 0.2초 정지 계약과 timeout 설정이 충돌하고, 중심 허용 영역에 footprint를 다시 검사하는 이중 축소는 계획된 회전을 막을 수 있다. FAULT 우선 반환이 IR latch를 놓치는 경우, 정지 명령을 받았지만 실제로 아직 움직이는 경우, IR/scan/EKF 입력이 죽었는데 정상으로 판단하는 경우를 명시적으로 처리해야 한다. AMCL TF는 센서 측정 시각과 같지 않으므로 TF freshness만으로 위치 추정의 생존·정확도를 판정할 수 없다. A_eff 숫자의 기본 산술은 맞지만 회전·SHIFT의 도구 궤적까지 포함하는지에 따라 정의가 달라진다. 자체 lane_follower와 비필수 트랙 B는 선택 가능한 방향이나, ‘Nav2 복구가 위험하므로 자체 제어가 더 안전하다’는 결론에는 동의하지 않는다. F2는 11/24 트랙 B 합격이 선행인데 11/18–19 대안 확정에 포함되어 일정상 사용할 수 없다.

아래 **필수 17건, 권장 5건, 선택 1건**을 제시한다. 필수는 해당 모듈의 구현 계약 또는 주행 시험 전에 고칠 사항이다. 모든 SW 작업을 멈추라는 뜻은 아니며, 패키지 골격·순수 함수·재현 시험 작성은 병행할 수 있다. **확인함**은 실제 공식 문서/소스 조회, **일반 지식**은 제어·기하·소프트웨어 원리와 문서 대조, **추정**은 조건부 계산, **확인 필요**는 실기나 설치 버전 미확인을 뜻한다.

## 수치 재계산과 구현 규약 제안

계획의 입력값을 그대로 사용한 **조건부 계산**이며 실기 정확도·제동 검증이 아니다.

| 항목 | 재계산 | 판정 |
|---|---|---|
| 직선 정지 거리 | `0.08×0.15 + 0.08²/(2×0.5)=0.0184m` | ‘약0.02m’ 산술은 맞음. 0.2s/0.3s timeout 경로를 쓰면 τ=0.15s 가정과 맞지 않으므로 fault별 재계산 필요. |
| c_min, e_loc=0.03 | `max(0.070,0.045)+0.03+0.03=0.13m` | 산술은 맞음. 추가 오차의 포함 범위는 S-X-17 참조. |
| 중심 영역 | `(2.4−2×0.13)×(1.2−2×0.13)=2.14×0.94m` | 맞음. 이것을 다시 footprint 내부검사에 사용하지 않음. |
| lane 수·간격 | `ceil(0.94/0.08)+1=13`; 11개 간격0.08+마지막0.06 | 맞음. 시작 y=0.13, 끝 y=1.07이며 마지막 SHIFT는0.06. |
| 직선 전용 A_eff | `2.14×(0.94+0.10)=2.2256m²`; 패널 대비77.2778% | 표의2.23·약77%는 맞음. TURN/SHIFT는 정의 선택 필요. |
| e_loc=0.05로 확정될 경우 | c_min=0.15, 중심2.10×0.90, lane13/마지막0.02, 직선 A_eff=2.10m², 패널 대비72.9167% | G-LOC 합격 상한을 사용하면 초기 예시와 달라짐. 실측 후 자동 산출해야 함. |

## 공식 자료 확인 결과와 동의하는 판단

- **확인함:** `laser_filters`는 Jazzy release 대상이다. 현재 조회한 [rosdistro](https://github.com/ros/rosdistro/blob/master/jazzy/distribution.yaml)는 laser_filters **2.0.10-5**, robot_localization **3.8.4-1**, realsense2_camera **4.59.1-1**을 표시한다. 이것은 대상 Pi의 설치/실행 검증은 아니다.
- **확인함:** [Nav2 Jazzy TwistPublisher](https://github.com/ros-navigation/navigation2/blob/jazzy/nav2_util/include/nav2_util/twist_publisher.hpp)는 `enable_stamped_cmd_vel` 기본 false다. §5의 타입 호환 설명은 맞다. 다만 이 기본값이 unstamped command의 안전성을 보장하지는 않는다.
- **확인함:** AMCL parameter 이름 `update_min_d`, `update_min_a`, `base_frame_id`, `tf_broadcast`, `transform_tolerance`는 [Jazzy 소스](https://github.com/ros-navigation/navigation2/blob/jazzy/nav2_amcl/src/amcl_node.cpp)에 존재한다. 0.05m/0.1rad 선택을 부정할 이유는 없지만 실제 성능은 미확인이다.
- **확인함:** [Pinky IMU 소스](https://github.com/pinklab-art/pinky_pro/blob/main/pinky_imu_bno055/src/main_node.cpp)는 operation mode 0x08을 설정하고 gyro raw/16을 그대로 발행한다. 단위 수정과 orientation 미융합은 합리적이다. 기존 covariance 상수와 I²C 오류 검출까지 함께 수정해야 한다.
- **일반 지식:** §2.2 65–79행처럼 제어 경로를 Onboard에 두고 PC heartbeat 상실 시 멈추는 구조, §3 124행의 ROS 독립 코어, §7 339–345행의 실기/호스트 분리·실패 포함 기록은 유지한다. PC heartbeat timeout1s는 드라이버 명령 timeout0.2s와 다른 계약임을 명시하면 된다.
- **일반 지식:** 연구 범위를 빼고 사전 등록한 직사각형을 주행하는 결정, D455 외부 평가, F1 사용 시 평가 독립성을 다시 확보하는 원칙에 동의한다. 다만 panel/GT 등록의 수식과 오차 예산이 구현 명세가 되어야 한다.
- **일반 지식:** 트랙 B를 필수에서 뺀 결정에 동의한다. 별도 여유 인력이 없으면 병행 자체도 중단할 수 있어야 한다. 현재 F2를 조기 fallback처럼 제시하는 부분에는 동의하지 않는다.
- **일반 지식:** 자체 lane_follower를 선택하는 것 자체에는 반대하지 않는다. 하지만 검증되지 않은 새 제어기를 Nav2보다 더 안전하다고 미리 판정하는 근거는 부족하다. 단순화한 동작 계약과 실제 폐루프 시험으로 선택을 정당화해야 한다.
