# Pinky Solar — 개발 계획서 v5.0

- 과제: Pinky Pro 기반 태양광 패널 청소 로봇 — 주행 MVP
- 시연: 2026-11-28(토)
- 조건: 평평한 직사각형 모형 패널. 청소 장치 없음.
- 범위: 소프트웨어 개발과 시험 도구.

---

## 1. 시연에서 로봇이 하는 일

1. 패널 모서리 근처에 놓인 로봇이 두 끝단을 차례로 정면에서 보고 출발 위치를 스스로 맞춘다.
2. 패널을 평행 왕복(직진 → 끝단 앞 정지 → 줄 바꿈)으로 끝까지 주행한다.
3. 끝단은 로봇이 직접 감지한다. 외부 위치 입력을 받지 않는다.
4. 마지막 줄을 마치면 정지한다.
5. 패널 밖으로 떨어지지 않는다.

---

## 2. 동작 원리

### 2.1 패널 위에 머물기

- **끝단 감지:** 전방 카메라로 끝단선을 찾는다. d는 주행 폭(차체 폭 + 여유) 안에서 진행 방향으로 끝단을 처음 만나는 지점까지의 거리이고, ψ는 그 끝단선의 각도다.
- **끝단선 기억:** 관측한 끝단선은 odom 좌표로 기억하고, 로봇이 움직이거나 돌면 이동량으로 갱신한다. 주행 폭 밖을 나란히 지나는 끝단선은 기억만 하고 감속·정지에는 쓰지 않는다.
- **정면 접근 원칙:** 로봇은 모든 끝단을 정면으로 본 뒤에만 다가간다.
- **감속과 정지:**
  - 끝단이 보이지 않고 전방이 패널로 확인되는 동안은 주행 속도로 간다.
  - d가 감속 거리 안으로 들어오면 접근 속도로 낮춘다.
  - d가 정지 거리가 되면 멈춘다.
- **사각 지대:** 끝단이 카메라 시야 아래로 들어가면 기억한 끝단선으로 거리를 계속 계산한다. 줄 끝에 멈춘 상태와 회전 중에도 같다.
- **회전 허가:** 제자리 회전 때 뒤쪽 캐스터가 반경 r\_swing의 호를 그린다. 캐스터가 도는 쪽의 기억한 끝단선까지 로봇 중심 거리가 c\_turn 이상일 때만 회전한다.
- **정지 목표와 회전 허가의 간격:** 줄 끝 정지 목표 c\_end는 c\_turn보다 정지 오차만큼 크게 잡는다. 정지 후 거리가 c\_turn보다 작으면, 방금 지나온 직선 위로 접근 속도로 짧게(0.05 m 이내) 후진해 c\_end를 맞춘다. 그래도 안 되면 정지하고 운영자를 기다린다.
- **판정 불가:** 영상이 끊기거나 패널인지 판정할 수 없으면 전진을 멈춘다.
- **하향 IR:** 지지면이 사라지면 즉시 정지한다. 패널 표면에서 쓸 수 있는지는 D1 측정으로 정한다(§7).

### 2.2 줄을 똑바로 가기

- **Heading:** 자이로 각속도 적분으로 유지한다. 정지할 때마다 자이로 바이어스를 다시 잡는다.
- **줄 끝 보정:** 줄 끝마다 끝단선 각도 ψ로 Heading을 끝단에 수직으로 맞춘다. ψ의 반복 편차가 자이로 오차보다 크면, 한 번에 맞추지 않고 여러 줄의 ψ를 평균해 조금씩 보정한다.
- **줄 간격:** 바퀴 이동량으로 SHIFT 거리를 잰다.
- **허용 오차:** 인접한 두 줄 사이의 틈은 두 줄의 Heading 차이가 정한다. 줄 길이 2.2 m, 겹침 20 mm(가상 폭 0.10 m, 간격 0.08 m)에서 허용 Heading 차이는 약 0.5°다. 간격을 0.06 m로 줄이면 약 1.0°다.

### 2.3 왕복 패턴

좌표: 긴 변 방향이 x, 짧은 변 방향이 y. 로봇은 x = 0, y = 0 모서리 근처에 −x를 보고 놓인다. 놓는 위치는 두 끝단이 모두 카메라에 보이는 거리(가장 가까이 보이는 거리보다 먼 곳)다.

**출발 정렬(INIT)**

1. 끝단 A(x = 0)를 정면으로 보고 ψ로 수직 정렬한다. 중심–끝단 거리가 c\_end가 될 때까지 다가간다.
2. 좌회전 90°로 측면 끝단(y = 0)을 정면으로 본다. 캐스터는 패널 안쪽으로 돈다.
3. 수직 정렬 후 중심–측면 끝단 거리가 c\_side가 될 때까지 다가간다.
4. 좌회전 90°로 +x를 본다. 캐스터는 끝단 A 쪽으로 돌고, 거리는 1에서 맞춘 c\_end다.

**줄 주행과 줄 바꿈(반복)**

1. STRAIGHT: Heading을 유지하며 직진한다. 끝단 B를 감지하면 감속하고, 중심–끝단 거리 c\_end에서 정지한다.
2. ALIGN: ψ로 수직 정렬한다.
3. TURN: +y 쪽으로 90° 회전한다. 캐스터는 지나온 줄 쪽으로 돈다. 첫 줄에서는 측면 끝단 쪽이며, 거리는 c\_side다.
4. 전방(+y)의 반대편 측면 끝단까지 거리를 잰다. 남은 폭이 줄 간격보다 작으면 마지막 줄 위치(c\_side)까지만 이동하도록 SHIFT 길이를 정한다.
5. SHIFT: 줄 간격만큼 직진한다.
6. TURN: 같은 방향으로 90° 더 회전한다. 캐스터는 끝단 B 쪽으로 돌고, 거리는 1에서 맞춘 c\_end다.
7. 반대 방향 줄을 같은 방식으로 주행한다. 끝단 A에서는 회전 방향이 반대다.

**종료:** 마지막 줄 끝에서 정지한다.

### 2.4 여유와 예상 수치


| 기호                              | 의미                     | 초기 추정          | 확정     |
| ------------------------------- | ---------------------- | -------------- | ------ |
| r\_swing                        | 캐스터 회전 반경              | 0.076 m (URDF) | D1 실측  |
| m\_turn                         | 끝단 거리 측정 오차 여유         | 0.01–0.02 m    | G-EDGE |
| c\_turn = r\_swing + m\_turn    | 회전을 허가하는 최소 중심–끝단 거리   | 약 0.09 m       | —      |
| c\_end = c\_turn + 정지 오차        | 줄 끝 정지 목표(중심–끝단)       | 약 0.10 m       | G-EDGE |
| c\_side = c\_turn + 줄 주행 중 횡 이동 | 첫 줄·마지막 줄의 중심–측면 끝단 거리 | 약 0.11 m       | M3     |


- 정지 시 차체 앞면과 끝단 사이는 c\_end − 0.06 ≈ 0.04 m다.
- 가상 청소 폭을 로봇 중심의 0.10 m로 두면 덮는 면적은 패널의 약 81–83%다(줄 14개).
- 남는 띠의 대부분은 캐스터 회전 반경에서 나온다.
- 1회 주행 시간은 약 10분이다(주행 0.08 m/s, 접근 0.03 m/s).

## 4. 끝단 감지

### 4.1 출력 상태


| 상태      | 의미                                  | 로봇 동작                   |
| ------- | ----------------------------------- | ----------------------- |
| EDGE    | 주행 폭 안에 끝단이 있다(관측했거나 기억 중). d, ψ 유효 | d에 따라 감속·정지             |
| CLEAR   | 주행 폭 안에서 전방 `clear_dist`까지 패널로 확인됐다 | 주행 속도 허용                |
| UNKNOWN | 판정할 수 없다(영상 이상, 외관 기준 불일치)          | 전진 정지. 회전은 기억한 끝단선으로 판정 |


### 4.2 방법

1. **바닥 좌표 변환:** 패널 위에 격자판을 놓고 영상 픽셀과 바닥 좌표의 대응(Homography)을 직접 보정한다. 카메라 각도를 바꾸면 다시 보정한다.
2. **패널 판정:** 로봇 바로 앞의 색·밝기 분포를 기준으로, 전방 각 지점이 패널인지 아닌지 판정한다. 기억한 끝단선이 기준 영역에 가까워지면 기준 갱신을 멈추고 마지막 기준을 유지한다.
3. **끝단선:** 영상 열마다 패널이 끝나는 첫 지점을 찾고, 그 점들에 직선을 맞춘다. 패널의 셀 무늬 선은 선 건너편이 다시 패널이므로 끝단으로 보지 않는다.
4. **d와 ψ:** 찾은 끝단선 중 주행 폭 안을 가로지르는 선으로 d와 ψ를 구한다. 주행 폭 밖을 나란히 지나는 선은 기억에만 넣는다.
5. **시간 일관성:** 연속 프레임에서 이동량만큼 d가 줄어드는지 확인한다. 한 프레임만 나타난 끝단은 감속에만 쓰고 정지에는 쓰지 않는다.
6. **끝단선 기억:** 확인된 끝단선을 odom 좌표로 저장한다. 시야 밖(사각 지대, 회전 중)에서는 저장한 선과 이동량으로 d를 계산한다.

### 4.3 합격 기준 (G-EDGE)

실제 모형 끝단에서 시험한다.


| 항목                      | 기준                           |
| ----------------------- | ---------------------------- |
| 정면 접근                   | 20회 모두 정지. 정지 위치 오차 15 mm 이하 |
| 사선 접근(±15°, ±30°)       | 각 10회 모두 정지                  |
| 패널 내부 주행                | 전체 왕복 1회 동안 오정지 0회           |
| 판정 불가 주입(카메라 가림, 영상 중단) | 10회 모두 정지                    |
| 처리 주기                   | 로봇에서 15 Hz 이상                |


### 4.4 불합격 시 절차

합격할 때까지 반복한다.

1. 실패 장면의 영상 기록을 재현 시험 묶음에 추가한다.
2. 원인을 분류한다: 카메라 설정, 패널 판정, 끝단선 맞춤, 추적, 처리 속도.
3. 원인에 맞게 고친다.
   - 카메라 설정: 노출·화이트밸런스 고정값. 기울기는 거치대가 조절될 때만 바꾸고, 고정이면 거치대 변경을 요청한다
   - 패널 판정: 색 공간, 질감 특징, 기준 영역 갱신 방식, 기록 영상으로 학습한 분류기
   - 처리 속도: 해상도·관심 영역 축소
4. 재현 시험 묶음을 전부 통과하면 로봇에서 다시 시험한다.

## 5. 안전 규칙 (`safety_stop`)

1. 모터 명령은 `safety_stop`만 보낸다. 명령은 끊김 없이 주기적으로 보내고, 드라이버는 명령이 끊기면 정지한다.
2. `/edge`가 일정 시간 넘게 오지 않으면 모든 동작을 멈춘다. UNKNOWN이면 전진을 멈춘다.
3. 전진 속도 상한: CLEAR면 주행 속도, EDGE이고 d가 감속 거리 이하면 접근 속도, d가 정지 거리 이하면 0.
4. 회전은 캐스터가 도는 쪽의 기억한 끝단선까지 거리가 c\_turn 이상일 때만 통과시킨다.
5. IR이 지지면 소실을 감지하면 정지하고, 운영자가 해제할 때까지 유지한다(IR을 쓰기로 정한 경우).
6. `/stop`을 받으면 정지한다.
7. 후진은 방금 지나온 직선 위에서 0.05 m 이내, 접근 속도로만 통과시킨다.

실제 모형 위 자율 주행은 M1(바닥 표면재에서 끝단 앞 정지)을 통과한 뒤에 시작한다. 모형 위 시험은 접근 속도로 시작하고, 완충 매트를 깔고 사람이 옆에서 대기한 상태로 한다.
